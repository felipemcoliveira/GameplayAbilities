# GameplayAbilities

This repository is the Unity implementation introduced in [Gameplay Tags, Part 1: Core Concepts](https://felipemcoliveira.com/blog/gameplay-tags-data-driven-abilities/).

Part 1 looks at how Unreal's Gameplay Ability System uses tags and effects to express gameplay rules as data. Part 2 will build the foundation in Unity: reusable gameplay effects, source and target tags, and rules that decide when an effect applies or changes magnitude.

Open the repository root in Unity **6000.4.10f1**. The project uses **URP 17.4.0** and starts with `Assets/Scenes/Main.unity`, a scene with a camera and directional light. Implementation will follow as Part 2 takes shape.
